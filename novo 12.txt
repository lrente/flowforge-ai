==================================================
EXECUTION MODEL
==================================================

Example:

Trigger
  ↓
AI Agent
  ↓
Knowledge Search
  ↓
HTTP
  ↓
Condition
  ↓
Create Ticket

Execution engine:

1. Find trigger/start node.
2. Execute node.
3. Store node result.
4. Find next node.
5. Evaluate connection/condition.
6. Execute next node.
7. Continue until workflow completes.

Pseudo:

while currentNode != null:

    validate node

    create execution log

    execute node

    save result

    determine next node

    continue

Return execution result.
